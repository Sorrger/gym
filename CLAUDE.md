# Gym – osobista aplikacja treningowa (PWA na iPhone)

Read this first in every session. It is the project's memory: who the user is, how the app works, how to ship.

## User
- Owner: GitHub `Sorrger`. Uses the app on an iPhone 16 as a home-screen web app. No Mac.
- Writes in Polish, often fast with typos. **Reply in Polish, short and simple, non-technical.** Give clear step-by-step instructions when they must do something on the phone.
- Prefers that you finish things completely (build, test, deploy) instead of handing work back.

## Live app / deploy
- URL: https://sorrger.github.io/gym/ (GitHub Pages, source = branch `main`, folder `/docs`).
- **Ship = `npm run deploy`** (scripts/deploy.mjs): builds into `docs/`, commits, pushes `main`. Pages updates in ~1 min.
  `docs/` is build output: never edit it by hand, always rebuild.
- In a cloud session (Claude app on the phone / claude.ai/code): `npm ci` first, then edit, `npm run build` to check, `npm run deploy` to publish.
  The live site only changes when `docs/` lands on `main`. If the session can only push to its own `claude/...` branch,
  open a PR and tell the user in one line to tap "Merge" in the GitHub app – after merging, the app updates in ~1 min.
- If Pages ever serves an old version after a push: `gh api -X POST repos/Sorrger/gym/pages/builds` re-triggers the build.
- The phone gets the new version on next open/return to the app: full-screen "Aktualizacja" with a progress ring (src/updater.js), then reload.

## Stack
Vite + Vue 3 + Ionic Vue 9 (mode `ios`), vue-router hash history, idb-keyval (IndexedDB), Chart.js, vite-plugin-pwa (injectManifest, `src/sw.js`).

## Files
- `src/plan.js` – the training plan (PLAN, COLORS, UNITS). Multi-part exercises (e.g. "Nauka podciągania" = Wiszenie (s) + Negatywy (reps)) via `groupsOf`/`entriesOf`; each part stored under key `"Name · Part"`. A plain exercise can set its unit as 4th element instead of parts (`[name, target, null, 'reps']`, e.g. captain's chair).
  **Pull-up stages (automatic, Nov 21 2026, user asked):** "Nauka podciągania" (Pull + Upper) is `['Nauka podciągania', null, tag, 'stages']`; parts come from `PULLUP_STAGES` in plan.js: 1 Wiszenie 3×20-30 s + Negatywy 3×3-5 → 2 Ze wspomaganiem (assisted machine, kg = help, ASSISTED, INC 5) 3×6-8 + Negatywy 2×3-5 → 3 Pełne 3×1-3 + Negatywy 2×3-5 → 4 Pełne 3×3-6. Goals (`stageGoalMet`, one non-deload workout): 1→2 3×30 s hang AND 3×5 negatives; 2→3 3×8 at ≤15 kg help; 3→4 3×3 full. `pullupStage()` in store walks history (highest stage seen, +1 on goal) → `setStageFn`. `groupsOf(ex, ctx)` / `entriesOf(day, ctx)`: ctx = a session (its own stage from its keys, `stageOfSession`), `'all'` (all parts reached so far – progress views, stats) or nothing (current stage). `targetOf(ex, ctx)` = "Etap n/4 · …". Coach shows kind `stage` ("Nowy etap n/4 🎉") for a new part; HARDER keys may have `@stage`. Always pass the session as ctx where a session exists. Stage 2 first prefill falls back to the old "Podciąganie nachwytem (wspomagane)" numbers. Assisted kg (help) is excluded from volume and records use "less = better" (series, ExerciseView, Strava).
  **Automatic deload (Nov 21 2026, user asked, after research: Bell 2023 Delphi, Rogerson 2024 survey ~every 5.6 wk ~6.4 days, Coleman 2024: full week off cost a bit of strength → light week, not rest):** `deloadState()` in store: due after 6 weeks of training (DELOAD_EVERY) or from week 4 (DELOAD_MIN) when ≥60 % of 5+ tracked exercises had no new best in their last 2 workouts; a gap of 8+ days = rest, count restarts. New workout when due/active → `deload: true`: half the sets (ceil), kg ×0.9 rounded to INC (assisted: +1 step help), reps = bottom of range, 3-4 left; lasts 7 days from its first workout. Coach history, prefill of later workouts, stage goals and strength index skip deload workouts (numbers come back after). Workout chip "Tydzień lżejszy" → "Dziś trenuj normalnie" = `cancelDeload()` (full plan, `noDeload: true`, deload postponed a week). Home card + PlanView note; Strava first line gets "· tydzień lżejszy".
  Upper also starts with "Nauka podciągania" (replaced assisted pull-ups, Nov 2026, user; old assisted history kept under its own name). Abs: Pull ends with captain's chair (reps) + Allahy; Nogi ends with Pallof press (user called it "hammer press": sideways to the cable, press out, hold 2 s, per side) + captain's chair + Allahy.
- **Progression (double progression)** – `src/coach.js` `suggest(group, session)`; rep range comes from the target (`rangeOf('3 × 6-8')`), per-exercise kg step in `INC` (default 2,5), `ASSISTED` (less kg = harder), `HARDER` texts for bodyweight/time parts – all in plan.js.
  All planned sets at the top of the range → +INC (2×INC if every set was 3+ reps over the top) and start at the bottom; else same weight, +1 rep per set; ~10 % lighter only when two workouts in a row at that weight had a set below the bottom AND total reps did not improve (8,7,6 after a jump is normal). New workouts always get the planned number of sets (user asked).
  **Reps in reserve ("Zapas")**, optional per set: after ticking a set (not for seconds) chips 0 / 1 / 2 / 3+ appear, stored as `q` (3 = 3+). Coach: every set 3+ left (and at least the bottom of the range) → add weight now ("za lekko"); next-time reps per set +0 for 0 left, +1 for 1-2 (or unknown), +2 for 3+. Auto-jump to the next exercise waits up to 5 s for a Zapas tap on the last set (jumps 0,6 s after the tap). Shown in SessionView sets and the hint text.
  **Live advice during the workout (Nov 21 2026, user asked):** `live(g, session)` in coach.js – after a ticked kg set, only clear cases: below the range with 0/unknown left → ~10 % lighter (≥1 step) × bottom of range; 3+ left at the top or 3+ reps over → +1 step (assisted inverted; none in deload). Shown as a short red/green bar right under the set it is about (so it stays in view on small screens) with "Ustaw" (fills unticked sets); disappears when the sets already have that weight.
  **Warm-up note (Nov 21 2026, user asked):** `WARMUP` (bar kg) for bench, Zercher, seated OHP, RDL → `warmupSets(W)`: bar × 10, 50 % × 8, 70 % × 5, 85 % × 2 (rounded 2,5, skipped if ≤ previous or ≥ work weight) + `platesPerSide`.
